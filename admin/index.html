Akun Guru

Buat akun masuk untuk guru. Setiap guru terhubung ke satu sekolah dan hanya melihat data sekolah itu.

Buat akun baru

Isi sekolah, nama, email masuk, dan kata sandi. Email dipakai hanya untuk login (boleh format internal, bukan email pribadi).

Perawatan data

Menu ini hanya dipakai saat pindah ke sistem multi-sekolah atau memperbaiki data lama. Untuk pemakaian harian, abaikan halaman ini.

Data sekolah awal (Kukusan)

Jika daftar sekolah masih kosong, tekan tombol di bawah untuk menambahkan SD Muhammadiyah 01 Kukusan secara otomatis.

Tandai data lama dengan sekolah

Paket soal, nilai, dan siswa yang dibuat sebelum sistem multi-sekolah belum punya penanda sekolah. Proses ini menambahkan penanda tersebut agar data tidak tercampur antar sekolah.

Buka alat penanda data

Import Siswa

Unggah daftar siswa sekaligus. Tiap baris minimal berisi nama lengkap dan NISN. Kata sandi masuk siswa = NISN.

Unggah daftar

File berformat JSON (daftar). Contoh isi satu baris: nama, nisn, kelas (opsional). Pilih sekolah di bawah jika file tidak mencantumkan sekolah.
